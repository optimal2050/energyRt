# Attach bounds data to model parameters

Attach bounds data to model parameters

## Usage

``` r
apply_bounds_to_model(model, scenario_param, base_name, scenario = NULL)
```

## Arguments

- model:

  Multimod model

- scenario_param:

  energyRt bounds parameter

- base_name:

  Base parameter name (without Lo/Up suffix)

## Value

List with model and diagnostic info

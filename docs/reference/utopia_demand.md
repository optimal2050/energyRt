# UTOPIA electricity load shape

A deterministic relative electricity-load shape by timeslice, for the
three teaching calendars (replaces the vignette's former random load
curve).
[`utopia_profiles()`](https://energyRt.org/reference/utopia_profiles.md)
/ the vignette scale it by a region's annual demand and the timeslice
shares to get energy per timeslice.

## Usage

``` r
utopia_demand
```

## Format

A data.frame with columns `calendar`
(`s4_h24`/`m12_h24`/`utopia_seasons`), `timeslice` and `load` (relative,
mean ~1).

## See also

[`utopia_profiles()`](https://energyRt.org/reference/utopia_profiles.md),
[utopia_weather](https://energyRt.org/reference/utopia_weather.md),
[utopia_stock](https://energyRt.org/reference/utopia_stock.md)

# Run mosox on a GMPL model or data file

Run mosox on a GMPL model or data file

## Usage

``` r
mosox_run(...)
```

## Arguments

- ...:

  Arguments passed to
  [`en_mosox_run()`](https://energyRt.org/reference/en_mosox_run.md).

## Value

A list with the execution result.
